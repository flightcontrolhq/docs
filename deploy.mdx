Use these quickstarts to deploy framework applications to AWS with Ravion. Static sites run from S3 and CloudFront. Server applications run on ECS Fargate behind an Application Load Balancer.

<CardGroup cols={2}>
  <Card title="Static sites" icon="window-maximize" href="/deploy/astro">

  </Card>
  <Card title="Server applications" icon="server" href="/deploy/nuxt">
    Run Node-based frameworks on ECS Fargate behind an Application Load Balancer.
  </Card>
</CardGroup>

  placeholder repository and AWS account values before applying a file.
</Note>
