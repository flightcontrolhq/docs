## Human setup

Complete these steps before asking an agent to create or change infrastructure.

<Steps>
  <Step title="Sign up for a Ravion account">
    Open [Ravion signup](https://app.ravion.com/signup) and create your account. Ravion is free for individuals, and teams start with a free trial.

  </Step>

  <Step title="Connect your AWS account">
    Open [AWS accounts](https://app.ravion.com/org/settings/aws-accounts?connect=%7B%7D) and connect the AWS account where Ravion should provision infrastructure.

  </Step>

  <Step title="Connect your Git repository">
    Open [Git connections](https://app.ravion.com/org/settings/git-connections?modal=addConnection) and connect the Git repository(s) Ravion should use for app or Terraform source code.

    Can be skipped if you just want Ravion to deploy images from an image registry.

  </Step>

  <Step title="Install the Ravion agent skill">

    ```bash
    npx skills add https://www.ravion.com/SKILL.md
    ```

    The skill teaches your agent the workflows below. See [Ravion agent skill](/agent-skill).

  </Step>

  <Step title="Install the Docs MCP server">

    ```bash
    npx add-mcp https://www.ravion.com/docs/mcp --name ravion-docs
    ```

    The Docs MCP server lets agents search and read current Ravion documentation from their context window. See [Ravion Docs MCP](/mcp/overview).

  </Step>

  <Step title="Install the CLI and sign in">
    On macOS, install the Ravion CLI with Homebrew:

    ```bash
    brew install ravionhq/tap/ravion
    ```

    Or install it with the install script:

    ```bash
    curl -fsSL https://github.com/ravionhq/cli/releases/latest/download/install.sh | sh
    ```

    Then sign in:

    ```bash
    ravion login
    # If you belong to more than one organization, select the active organization:
    ravion switch
    ```


    See [Install the Ravion CLI](/cli/installation) and [Authentication](/cli/authentication).

  </Step>

</Steps>

## Ask your agent

The [Ravion agent skill](/agent-skill) carries the agent workflow: reading core concepts, generating and applying a project config file, dry runs and approvals, pipelines, deploys, and CI. Once it is installed, describe what you want:

```
Deploy this project to AWS with Ravion.
```

Agents that can fetch URLs but don't support skills work too:

```
Deploy this project with Ravion: https://www.ravion.com/SKILL.md
```

The agent asks you for the values only you can decide, such as the AWS account, region, and domain, and pauses for your approval before any change that modifies, replaces, or removes existing infrastructure.
