Deploy a Hono Node.js application on ECS Fargate behind an Application Load Balancer. Use Hono's Node adapter and bind the server to the ECS-provided port.

<DeployPrerequisites />

## Configure the deployment

Use a production script such as `node dist/index.js` after compiling your TypeScript entry point to `dist/index.js`.

```yaml ravion.yaml
project:
  givenId: hono-app
  name: Hono app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: hono-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: hono-production
      - givenId: web
        name: Hono web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: hono-production-web
          build_source: railpack
          source_repo: my-org/my-hono-app
          railpack_build_cmd: npm run build
          railpack_start_cmd: npm start
          build_infrastructure_type: ec2
          build_instance_size: c7a.4xlarge
          deployment_strategy: rolling
          container_port: 3000
          health_check_path: /
          health_check_matcher: 200-399
          capacity_provider: fargate
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

Hono's Node server examples use port `3000`. Configure `@hono/node-server` with `port: Number(process.env.PORT) || 3000` and bind to `0.0.0.0`.

## Apply and connect your domain

```bash
ravion project create --given-id hono-app --name "Hono app"
ravion project config apply hono-app --file ravion.yaml --dry-run
ravion project config apply hono-app --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to the Application Load Balancer.
