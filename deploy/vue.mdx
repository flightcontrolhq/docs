Deploy a Vue application built with Vite to S3 and deliver it through CloudFront. The default production output directory is `dist`.

<Prompt description="Set up this Vue app for Ravion static hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/vue as the source of truth and:
  1. Confirm this repository contains Vue and locate its app root in a monorepo.
  2. Inspect `package.json`, Vite or Vue CLI config, and router setup to detect the actual build command, `dist` output, base path, and SPA fallback requirement.
  3. Generate `ravion.yaml` with `rvn-aws-static`, SPA routing, and real AWS account, region, branch, repository, and output values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing missing AWS account IDs, repository slugs, project IDs, or output paths.
</Prompt>

## Configure the deployment

```yaml ravion.yaml
project:
  givenId: vue-site
  name: Vue site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: Vue site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: vue-site-production
          build_source: railpack
          source_repo: my-org/my-vue-app
          railpack_build_cmd: npm run build
```

Run `npm run build`, which invokes Vite and writes to `dist`. Use `VITE_*` variables for values embedded into browser code.

## Apply and connect your domain

```bash
ravion project create --given-id vue-site --name "Vue site"
ravion project config apply vue-site --file ravion.yaml --dry-run
ravion project config apply vue-site --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to CloudFront.
