Deploy FastAPI with Uvicorn on ECS Fargate behind an Application Load Balancer. FastAPI's deployment documentation uses an ASGI server rather than a development server.

<Prompt description="Set up this FastAPI app for Ravion ECS hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/fastapi as the source of truth and:
  1. Confirm this repository contains FastAPI and locate the app root in a monorepo.
  2. Inspect Python dependency files, the ASGI entrypoint, Docker files, and scripts to detect the real Uvicorn command, port, workers, and health path; bind to `0.0.0.0`.
  3. Generate `ravion.yaml` with `rvn-aws-network` + `rvn-ecs-cluster` + `rvn-ecs-web`, using real AWS account, region, repository, branch, and runtime values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing AWS account IDs, repository slugs, project IDs, Python module paths, or ports.
</Prompt>

## Configure the deployment

This example assumes `main.py` exports `app = FastAPI()`.

```dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

```yaml ravion.yaml
project:
  givenId: fastapi-app
  name: FastAPI app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: fastapi-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: fastapi-production
      - givenId: web
        name: FastAPI web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: fastapi-production-web
          build_source: dockerfile
          source_repo: my-org/my-fastapi-app
          dockerfile: Dockerfile
          container_port: 8000
          health_check_path: /
          health_check_matcher: 200-399
          capacity_provider: fargate
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

The default example uses port `8000`. Add `--workers` after validating your memory budget, and use `DATABASE_URL` for database-backed applications.

## Apply and connect your domain

```bash
ravion project create --given-id fastapi-app --name "FastAPI app"
ravion project config apply fastapi-app --file ravion.yaml --dry-run
ravion project config apply fastapi-app --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to the Application Load Balancer.
