Deploy the Vite output to S3 and deliver it through CloudFront. Ravion uses SPA routing so client-side routes resolve to `index.html`.

<Prompt description="Set up this Vite app for Ravion static hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/vite as the source of truth and:
  1. Confirm this repository contains the Vite app and locate its root in a monorepo.
  2. Inspect `package.json`, `vite.config.*`, and router setup to detect the real build command, `dist` output, base path, and SPA fallback requirement.
  3. Generate `ravion.yaml` with `rvn-aws-static`, SPA routing, and real AWS account, region, branch, repository, and output values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing missing AWS account IDs, repository slugs, project IDs, or output paths.
</Prompt>

## Configure the deployment

```yaml ravion.yaml
project:
  givenId: vite-site
  name: Vite site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: Vite site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: vite-site-production
          routing: spa
          default_version: main
          build_source: railpack
          source_repo: my-org/my-vite-app
          output_directory: dist
          railpack_build_cmd: npm run build
```

Vite runs `npm run build` and writes to `dist`. Add variables needed by the browser as `VITE_*` build variables.

## Apply and connect your domain

```bash
ravion project create --given-id vite-site --name "Vite site"
ravion project config apply vite-site --file ravion.yaml --dry-run
ravion project config apply vite-site --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to attach your domain to CloudFront.
