Deploy a Solid single-page application to an S3 bucket behind CloudFront. Both resources are provisioned in your AWS account.

<Prompt description="Set up this Solid app for Ravion static hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/solid as the source of truth and:
  1. Confirm this repository contains Solid and locate the app root in a monorepo.
  2. Inspect `package.json`, Vite config, and router setup to determine the real build command, `dist` output, and SPA fallback requirements.
  3. Generate `ravion.yaml` with `rvn-aws-static`, SPA routing, and real AWS account, region, branch, repository, and output values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing missing AWS account IDs, repository slugs, project IDs, or output paths.
</Prompt>

## Configure the deployment

```yaml ravion.yaml
project:
  givenId: solid-site
  name: Solid site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: Solid site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: solid-site-production
          routing: spa
          default_version: main
          build_source: railpack
          source_repo: my-org/my-solid-app
          output_directory: dist
          railpack_build_cmd: npm run build
          build_infrastructure_type: ec2
          build_instance_size: c7a.4xlarge
```

The Solid Vite starter uses `npm run build` and writes to `dist`. Use `VITE_*` variables for values embedded in browser code.

## Apply and connect your domain

```bash
ravion project create --given-id solid-site --name "Solid site"
ravion project config apply solid-site --file ravion.yaml --dry-run
ravion project config apply solid-site --file ravion.yaml
```

Point DNS at the CloudFront hostname with [custom domains](/guides/custom-domains).
