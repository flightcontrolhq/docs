Run Remix on ECS Fargate behind an Application Load Balancer. Ravion provisions the VPC, cluster, service, and ALB in your AWS account.

## Configure the deployment

For the current Remix Vite workflow, `npm run build` creates `build/server/index.js` and `build/client`. Start the server with `npm start` or your adapter's documented start command.

```yaml ravion.yaml
project:
  givenId: remix-app
  name: Remix app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: remix-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: remix-production
          fargate_enabled: true
      - givenId: web
        name: Remix web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: remix-production-web
          build_source: railpack
          source_repo: my-org/my-remix-app
          source_base_path: .
          railpack_build_cmd: npm run build
          railpack_start_cmd: npm start
          build_infrastructure_type: ec2
          build_instance_size: c7a.4xlarge
          deployment_strategy: rolling
          container_port: 3000
          health_check_path: /
          health_check_matcher: 200-399
          capacity_provider: fargate
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

Set runtime configuration in `environment_variables` and keep secrets in `secrets`. Use the port supplied by ECS through `PORT`.

## Apply and connect your domain

```bash
ravion project create --given-id remix-app --name "Remix app"
ravion project config apply remix-app --file ravion.yaml --dry-run
ravion project config apply remix-app --file ravion.yaml
```

Use [custom domains](/guides/custom-domains) to attach your hostname.
