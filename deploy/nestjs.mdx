Deploy a NestJS server on ECS Fargate behind an Application Load Balancer. The Nest CLI production build writes JavaScript to `dist`, with the standard starter entry at `dist/main.js`.

<Prompt description="Set up this NestJS app for Ravion ECS hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/nestjs as the source of truth and:
  1. Confirm this repository contains NestJS and locate the app root in a monorepo.
  2. Inspect `package.json`, `nest-cli.json`, TypeScript config, and source bootstrap to detect the real build command, `dist` entrypoint, port, and health route; bind to `0.0.0.0` and `process.env.PORT`.
  3. Generate `ravion.yaml` with `rvn-aws-network` + `rvn-ecs-cluster` + `rvn-ecs-web`, using real AWS account, region, repository, branch, and runtime values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing AWS account IDs, repository slugs, project IDs, entrypoints, or ports.
</Prompt>

## Configure the deployment

```yaml ravion.yaml
project:
  givenId: nestjs-app
  name: NestJS app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: nestjs-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: nestjs-production
      - givenId: web
        name: NestJS web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: nestjs-production-web
          build_source: railpack
          source_repo: my-org/my-nestjs-app
          railpack_build_cmd: npm run build
          railpack_start_cmd: node dist/main.js
          container_port: 3000
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

Set the application to listen on `0.0.0.0` and use port `3000`, or read `PORT` from the environment. Add a health endpoint and change `health_check_path` when your app does not serve `/`.

## Apply and connect your domain

```bash
ravion project create --given-id nestjs-app --name "NestJS app"
ravion project config apply nestjs-app --file ravion.yaml --dry-run
ravion project config apply nestjs-app --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to the Application Load Balancer.
