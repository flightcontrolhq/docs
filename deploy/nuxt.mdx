Nuxt's Node server runs on ECS Fargate behind an Application Load Balancer. Ravion creates the VPC, ECS cluster, service, and load balancer in your AWS account.

<Prompt description="Set up this Nuxt Nitro app for Ravion ECS hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/nuxt as the source of truth and:
  1. Confirm this repository contains Nuxt and locate the app root in a monorepo.
  2. Inspect `package.json`, `nuxt.config.*`, Nitro settings, and runtime config to detect the real build/start commands, `.output` entrypoint, port, and health route.
  3. Generate `ravion.yaml` with `rvn-aws-network` + `rvn-ecs-cluster` + `rvn-ecs-web`, binding Nitro to `0.0.0.0` and `process.env.PORT`, with real AWS and repository values.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing AWS account IDs, repository slugs, project IDs, Nitro output, or ports.
</Prompt>

## Configure the deployment

Nuxt builds with `nuxt build` and starts with `node .output/server/index.mjs`. The server listens on port 3000.

```yaml ravion.yaml
project:
  givenId: nuxt-app
  name: Nuxt app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: nuxt-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: nuxt-production
      - givenId: web
        name: Nuxt web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: nuxt-production-web
          build_source: railpack
          source_repo: my-org/my-nuxt-app
          railpack_build_cmd: npm run build
          railpack_start_cmd: node .output/server/index.mjs
          container_port: 3000
          health_check_path: /
          health_check_matcher: 200-399
          capacity_provider: fargate
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

Set runtime values in `environment_variables`. Nuxt exposes browser-safe values through `runtimeConfig.public`; keep secrets in `secrets`.

## Apply and connect your domain

```bash
ravion project create --given-id nuxt-app --name "Nuxt app"
ravion project config apply nuxt-app --file ravion.yaml --dry-run
ravion project config apply nuxt-app --file ravion.yaml
```

Complete [custom domains](/guides/custom-domains) for the ALB hostname and TLS.
