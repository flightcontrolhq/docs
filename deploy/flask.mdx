Deploy Flask with Gunicorn on ECS Fargate behind an Application Load Balancer. Flask's production documentation recommends a dedicated WSGI server instead of the built-in development server.

<Prompt description="Set up this Flask app for Ravion ECS hosting." icon="sparkles" actions={["copy", "cursor"]}>
  Use https://www.ravion.com/docs/deploy/flask as the source of truth and:
  1. Confirm this repository contains Flask and locate the app root in a monorepo.
  2. Inspect Python dependency files, app modules, Docker files, and scripts to detect the real Gunicorn target, factory syntax, port, and health path; never use Flask's development server.
  3. Generate `ravion.yaml` with `rvn-aws-network` + `rvn-ecs-cluster` + `rvn-ecs-web`, using real AWS account, region, repository, branch, and runtime values. Bind Gunicorn to `0.0.0.0`.
  4. Run `ravion project config apply <given-id> --file ravion.yaml --dry-run`, show the plan, and apply only after confirmation.
  5. Leave TODOs instead of guessing AWS account IDs, repository slugs, project IDs, Python module paths, or ports.
</Prompt>

## Configure the deployment

This example assumes `app.py` exports `app`.

```dockerfile
FROM python:3.13-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
CMD ["gunicorn", "--bind", "0.0.0.0:8000", "app:app"]
```

```yaml ravion.yaml
project:
  givenId: flask-app
  name: Flask app
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: network
        name: Network
        type: rvn-aws-network
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: flask-production
      - givenId: cluster
        name: ECS cluster
        type: rvn-ecs-cluster
        version: 1.0.0
        input:
          network:
            moduleGivenIdRef: network
          name: flask-production
      - givenId: web
        name: Flask web service
        type: rvn-ecs-web
        version: 1.0.0
        input:
          cluster:
            moduleGivenIdRef: cluster
          name: flask-production-web
          build_source: dockerfile
          source_repo: my-org/my-flask-app
          dockerfile: Dockerfile
          container_port: 8000
          fargate_size:
            vcpu: 0.5
            memory_gb: 1
```

Gunicorn binds to port `8000` in this example. Use your application factory import path if the app is created by a function.

## Apply and connect your domain

```bash
ravion project create --given-id flask-app --name "Flask app"
ravion project config apply flask-app --file ravion.yaml --dry-run
ravion project config apply flask-app --file ravion.yaml
```

Follow [custom domains](/guides/custom-domains) to connect your domain to the Application Load Balancer.
