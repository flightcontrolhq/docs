Deploy the Docusaurus `build` directory to S3 and serve it globally through CloudFront. Ravion provisions the resources in your AWS account.

<DeployPrerequisites />

## Configure the deployment

```yaml ravion.yaml
project:
  givenId: docusaurus-site
  name: Docusaurus site
environments:
  - givenId: production
    name: Production
    moduleInstances:
      - givenId: static-site
        name: Docusaurus site
        type: rvn-aws-static
        version: 1.0.0
        input:
          aws_account_id: ravion-prod
          aws_region: us-east-1
          name: docusaurus-site-production
          routing: filesystem
          default_version: main
          build_source: railpack
          source_repo: my-org/my-docusaurus-site
          output_directory: build
          railpack_build_cmd: npm run build
          build_infrastructure_type: ec2
          build_instance_size: c7a.4xlarge
```

Docusaurus uses `npm run build` and writes the production site to `build`. Put public build-time settings in `build_environment_variables`.

## Apply and connect your domain

```bash
ravion project create --given-id docusaurus-site --name "Docusaurus site"
ravion project config apply docusaurus-site --file ravion.yaml --dry-run
ravion project config apply docusaurus-site --file ravion.yaml
```

Point your domain at the CloudFront hostname and complete [custom domains](/guides/custom-domains).
