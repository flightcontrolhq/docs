## Platform
### Features
- **[Public module catalog](https://www.ravion.com/docs/module-definitions/catalog):** Browse globally published active modules without signing in.
- **Stack run details:** Review infrastructure, workspace, output, and run information in a redesigned tabbed view with configuration changes and run context.
- **Nested module references:** Use module references inside object maps and arrays.
- **Graph canvases:** Explore module, pipeline, and task-health relationships in new production graph views.
### Improvements
- **Progressive list loading:** Large collections begin rendering as pages arrive instead of waiting for the entire result.
- **Run status visibility:** Project and module lists show the latest non-cancelled pipeline or stack run status with less flicker.
### Fixes
- **Invitation acceptance:** Accept organization invitations through a clearer flow for both password and OAuth sign-ins.
- **Pipeline retry checkpoints:** Retry failed pipeline steps while preserving successful steps and correctly handling skipped steps.
- **EC2 deployment recovery:** Failed EC2 deployments can automatically restore the previous successful release, and new instances are gated while their release is applied.
- **Module configuration references:** Preserve mapped values when changing module versions, resolve dynamic values correctly, and avoid showing false configuration differences.
- **Stack run navigation:** Breadcrumbs and run descriptions now point to the correct pipeline context and use clearer labels.
## CLI [0.2.5](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.5) → [0.2.15](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.15)
### Features
- **[Invitation lookup](https://www.ravion.com/docs/cli/reference/membership):** Look up a pending invitation with `ravion membership get-invitation invitationToken`.
- **[Invitation signup](https://www.ravion.com/docs/cli/reference/signup):** Use the invitation token from an invite link with the signup command to accept the invitation during signup.
- **[Bug and feedback reports](https://www.ravion.com/docs/cli/reference/report):** Submit multiline Markdown bug reports and product feedback with `ravion report bug` or `ravion report feedback`.
### Improvements
- **[Session continuity](https://www.ravion.com/docs/cli/authentication):** Keep active CLI sessions signed in by rotating refresh tokens before they expire.
### Fixes
- **Session recovery:** `ravion whoami` now identifies expired or revoked sessions as logged out and directs you to `ravion login`.
