## Platform

### Features

- **Public module catalog:** Anyone can browse globally published active modules without signing in.
- **Nested module references:** Module references now work inside object maps and arrays.
- **EC2 launch release gates:** New Auto Scaling instances can receive the latest successful release before joining service.

### Improvements

- Collections now render records as pages arrive instead of waiting for the full result.
- Pipeline runs and stack resources now load additional records as you scroll.
- Stack run details now show configuration changes, run context, outputs, and execution information in a clearer layout.
- Projects and stacks now show the newest non-cancelled run without an additional loading flicker.
- Module, pipeline, and task-health graphs now use clearer, more consistent layouts.

### Fixes

- Accepting an organization invitation now works reliably through email/password and OAuth sign-in.
- Retrying failed pipeline steps now preserves successful steps and reports the correct retry state.
- Dynamic values based on selected module references now load correctly, and mapped values remain when changing module versions.
- Module configuration diffs no longer show changes caused only by server-resolved reference values.
- Module definition pages now include the Catalog breadcrumb.
- EC2 deployment failures can now automatically restore the previous successful release.

## CLI [0.2.5](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.5) → [0.2.15](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.15)

### Features

- **Invitation lookup:** `ravion membership get-invitation invitationToken` now shows the organization, invitee, and status for an invite link.
- **Invitation signup:** `ravion signup --invitation invitationToken` now accepts the invitation during signup.
- **Module catalog access:** Module catalog list requests can now return globally published modules without authentication.
- **Nested module references:** Module references now work inside object map and array inputs.
- **Pipeline retry details:** Pipeline step executions now identify the retry attempt and explain skipped or cancelled steps.
- **EC2 rollback data:** `deploy rollback-candidates` now includes EC2 deployments and reports automatic rollback progress.
- **Latest run status:** Pipeline and stack responses now include the newest non-cancelled run and its status.
- **Bug and feedback reports:** `ravion report bug`, `ravion report feedback`, `ravion bug`, and `ravion feedback` now submit Markdown reports from the terminal. ([Report bugs and feedback](https://www.ravion.com/docs/report-bugs-and-feedback))

### Fixes

- **CLI sessions:** Active sessions now remain signed in through proactive refresh, and `ravion whoami` reports expired or revoked sessions as logged out. ([Authentication](https://www.ravion.com/docs/cli/authentication))
