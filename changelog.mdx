## Platform
### Features
- **[Public module catalog](https://www.ravion.com/docs/module-definitions/catalog):** Anyone can browse globally published modules without signing in.
- **Nested module references:** Module references now work inside object map and array inputs.
### Improvements
- Lists now render records as each page arrives and load more pipeline runs and stack resources as you scroll.
- Stack run details now show configuration diffs, workspace information, outputs, and run context.
- Pipeline and stack pages now show the newest non-cancelled run without an extra loading flicker.
### Fixes
- Breadcrumbs on module definition pages now link back to the catalog correctly.
- Invitation acceptance now works for matching email and OAuth sign-ins, including users without an existing organization.
- Retrying failed pipeline steps now restores the last successful checkpoint and reports skipped-step reasons.
- Dynamic values and saved mapped inputs for module references now remain correct during creation and version changes.
- Module configuration diffs no longer show server-resolved reference values as user changes.
## CLI [0.2.5](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.5) → [0.2.15](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.15)
### Breaking changes
- **Removed raw webhook payloads:** Use the dedicated `trigger_source` and `webhook_event` fields instead.
- **Renamed invitation identifiers:** Pass the invitation token from the invite link to `--invitation` instead of an invitation ID.
### Features
- **[Invitation lookup](https://www.ravion.com/docs/cli/reference/membership):** Run `ravion membership get-invitation invitationToken` to view a pending invitation's organization, invitee, and status.
- **[EC2 deployment rollback](https://www.ravion.com/docs/cli/reference/deploy):** `deploy rollback-candidates` now returns EC2 candidates and reports automatic rollback progress.
- **EC2 launch release gates:** Deployment data now exposes the release gate and its applied release for new Auto Scaling instances.
- **Pipeline retry details:** Step execution responses now identify the retry attempt and explain skipped or cancelled steps.
- **Latest run status:** Pipeline and stack responses now include the newest non-cancelled run's ID and status.
- **[Bug and feedback reports](https://www.ravion.com/docs/cli/reference/report):** Submit multiline Markdown with `ravion report bug`, `ravion report feedback`, `ravion bug`, or `ravion feedback`.
### Improvements
- **[Session refresh](https://www.ravion.com/docs/cli/authentication):** Active CLI sessions now roll refresh tokens before expiry and remain usable when a temporary refresh fails.
## AWS account IAM policy 1.0.38 → 1.0.39
- **EC2 launch release gates:** AWS account policies now allow lifecycle heartbeats and completion for fail-closed EC2 launch release gates.
Update your AWS account connection in organization settings.
