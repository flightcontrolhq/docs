## Platform

### Features

- **Added anonymous access to the [module catalog](https://www.ravion.com/docs/module-definitions/catalog):** Anyone can browse globally published, active modules without signing in.
- **Added nested module references:** Module references now work inside object maps and arrays, with clearer dependency tracking through the [reference input schema](https://www.ravion.com/docs/module-definitions/definition-schema#refinputproperty).

### Improvements

- **Improved collection loading:** Long lists now render progressively and load additional results as you scroll.
- **Improved stack run details:** The redesigned view organizes infrastructure, workspace information, outputs, and run details into tabs with clearer change context.
- **Improved graph layouts:** Module and pipeline canvases now arrange connected resources more clearly and avoid overlapping frames and links.
- **Improved run status visibility:** Project and module views now show the latest non-cancelled run status without flicker.

### Fixes

- **Fixed invitation acceptance:** Invite links now work consistently across email/password and OAuth sign-in, with clearer handling when the signed-in email does not match.
- **Fixed pipeline retries:** Retrying failed steps now preserves successful work and correctly explains skipped or cancelled steps.
- **Fixed module reference editing:** Dynamic values remain available while creating or changing references, saved mapped values are preserved, and unchanged server-resolved values no longer appear as edits.
- **Fixed navigation breadcrumbs:** Module definition and pipeline run pages now link back to the relevant catalog or pipeline list.
- **Fixed failed EC2 deployments:** Deployments can automatically restore the prior successful release after an execution failure, and new instances wait for a release before joining service.

## CLI [0.2.5](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.5) → [0.2.15](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.15)

### Breaking changes

- **Removed raw webhook payloads:** Pipeline run trigger metadata now uses dedicated fields such as `trigger_source` and `webhook_event` instead; update clients that read `webhook_payload`.
- **Renamed the invitation input:** The `--invitation` option now expects the invitation token from the invite link instead of an invitation ID.

### Features

- **Added invitation lookup:** `ravion membership get-invitation invitationToken` shows the organization, invitee, and status for a pending invitation.
- **Added bug and feedback reports:** `ravion report bug|feedback`, `ravion bug`, and `ravion feedback` submit Markdown reports from the terminal.
- **Added retry context to step results:** Pipeline step responses now identify the retry attempt and explain skipped or cancelled steps.
- **Added deployment rollback details:** EC2 deployment responses now include rollback candidates, automatic rollback progress, and launch release-gate status.
- **Added run and creation context:** Pipeline and stack responses include the latest run ID and status, while run responses can include the captured configuration and creator.

### Improvements

- **Improved CLI session continuity:** Active sessions now refresh before expiry, coordinate token rotation across concurrent commands, and continue using a valid access token when refresh temporarily fails.

### Fixes

- **Fixed expired-session guidance:** `ravion whoami` now reports expired or revoked sessions as logged out and directs you to `ravion login`.
