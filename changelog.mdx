## Platform
### Features
- **Public module catalog:** Anyone can browse globally published modules without signing in. [Module catalog](https://www.ravion.com/docs/module-definitions/catalog)
- **Nested module references:** Module references now work inside object maps and arrays. [Module definition schema](https://www.ravion.com/docs/module-definitions/definition-schema)
- **Task health canvas:** Task health is now visualized alongside module and pipeline graphs.
### Improvements
- Collections now render progressively as additional pages load, and pipeline runs and deployments load more results as you scroll.
- Stack run details now show configuration diffs, workspace information, outputs, and run context.
- Module and pipeline graph layouts now arrange nodes and connections more clearly.
- Project and module pages now show the latest run status without extra loading flicker.
### Fixes
- Invitation acceptance now works across email, password, and OAuth sign-in flows.
- Retrying failed pipeline steps now preserves successful steps and reports the correct status.
- Dynamic module reference selectors now retain mapped values when creating or changing module versions.
- Module configuration diffs no longer show changes caused only by server-resolved reference values.
- Breadcrumbs on module definition and pipeline run pages now link correctly.
- Failed EC2 deployments now automatically restore the previous successful release when eligible.
## CLI [0.2.5](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.5) → [0.2.15](https://github.com/flightcontrolhq/cli/releases/tag/v0.2.15)
### Breaking changes
- **Removed raw webhook payloads:** Use the dedicated trigger source and webhook event fields instead.
- **Changed invitation input:** Use the invitation token from the invite link with signup and invitation lookup commands.
### Features
- **Invitation lookup:** `ravion membership get-invitation invitationToken` shows pending invitation details by invite-link token.
- **Nested module references:** CLI responses now support references inside object maps and arrays and identify each occurrence's JSON pointer path.
- **Run status summaries:** Pipeline and stack responses now include the newest non-cancelled run's ID and status.
- **Bug and feedback reports:** `ravion report bug`, `ravion report feedback`, `ravion bug`, and `ravion feedback` submit reports from the terminal. [Report bugs and feedback](https://www.ravion.com/docs/report-bugs-and-feedback)
- **EC2 rollback details:** Deployment commands now expose EC2 rollback candidates, automatic rollback progress, and launch release gate status. [Deploy](https://www.ravion.com/docs/cli/reference/deploy)
### Fixes
- **Session continuity:** CLI sessions now stay signed in by rolling refresh tokens before expiry. [Authentication](https://www.ravion.com/docs/cli/authentication)
- **Expired session guidance:** `ravion whoami` now reports expired or revoked sessions as logged out and directs users to `ravion login`.
- **EC2 deployment responses:** Older EC2 deployment records no longer fail response validation when account data is absent.
## AWS account IAM policy 1.0.38 → 1.0.39
- **EC2 launch release gates:** Auto Scaling lifecycle heartbeat and completion permissions now support fail-closed EC2 launch release gates.

Update your AWS account connection in organization settings.
