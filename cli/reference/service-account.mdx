## `ravion service-account`

Manage service accounts

**Aliases:** `service-accounts`

### `ravion service-account create`

Create ServiceAccount

```bash
ravion service-account create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--name <string>` | yes | User-facing service account name. |
| `--role <string>` | yes | Organization role used when this service account authenticates. Available values: OWNER. |
| `--description <string>` |  | Optional context for what this service account is used for. |
| `--json` |  | emit response as JSON |
