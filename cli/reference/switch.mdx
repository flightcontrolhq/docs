## `ravion switch`

switch walks through the authenticated user's organizations and persists the pick so subsequent commands run in that context. Switching organization clears the selected Terraform state workspace — `ravion terraform shell` will ask you to pick one next. Use --org to skip the picker.

**Aliases:** `use`, `org`

```bash
ravion switch [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--org <string>` |  | organization id or name to select (skip the picker) |
