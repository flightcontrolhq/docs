## `ravion module`

Manage module instances

**Aliases:** `modules`, `mod`

### `ravion module create`

Create ModuleInstance

```bash
ravion module create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--environment-id <string>` | yes | Environment ID where this instance is deployed |
| `--given-id <string>` | yes | User-provided unique identifier. Must be unique within environment. |
| `--input <string>` | yes | Configuration input object for the module instance |
| `--module-definition-id <string>` | yes | Module definition ID |
| `--module-version-id <string>` | yes | Module version ID for the current configuration |
| `--name <string>` | yes | User-provided instance name. |
| `--description <string>` |  | Optional description of the module instance. |
| `--initial-stack-run <string>` |  | Initial stack run behavior after creating a stack-backed module instance. Defaults to NONE. PLAN starts a stack run. APPLY starts a stack run with the autoapprove input enabled. Available values: NONE, PLAN, APPLY. |
| `--json` |  | emit response as JSON |
