## `ravion default-value`

Manage default values

**Aliases:** `default-values`

### `ravion default-value create`

Create DefaultValue

```bash
ravion default-value create [flags]
```

**Flags:**

| Flag | Required | Description |
| --- | --- | --- |
| `--default-value-definition-id <string>` | yes | Definition this value belongs to. |
| `--parent-id <string>` | yes | Organization, project, or environment ID matching the parent type. |
| `--parent-type <string>` | yes | Scope where this value is defined. Available values: organization, project, environment. |
| `--value <string>` | yes | Raw value matching the definition schema. |
| `--json` |  | emit response as JSON |
