## ProjectConfig

User-authored project config file consumed by `ravion projects config apply --file`.

- **`project`**: [Project](#project) — optional. Project metadata to update before applying environment configuration.
- **`environments`**: [Environment](#environment)[] — required. Environment configuration blocks to apply.

## Project

Writable project metadata accepted by project config apply.

- **`id`**: string — optional. Existing project ID. When provided, it must match the project in the route.
- **`givenId`**: string — optional. User-provided project identifier. When provided, it must match the project in the route.
- **`name`**: string — optional
- **`description`**: string — optional

## Environment

Environment block authored in project config files.

- **`id`**: string — optional. Existing environment ID.
- **`givenId`**: string — optional. User-provided environment identifier.
- **`name`**: string — optional
- **`description`**: string — optional
- **`moduleInstances`**: [ModuleInstance](#moduleinstance)[] — required

## ModuleInstance

Module instance shape authored in project config files.

- **`id`**: string — optional. Existing module instance ID. Non-empty IDs must resolve to an existing module.
- **`givenId`**: string — optional. User-provided unique identifier. Must be unique within environment.
- **`name`**: string — optional
- **`description`**: string — optional
- **`type`**: string — optional. Module type identifier.
- **`version`**: string — optional. Semantic module version string.
- **`input`**: map&lt;string,any \| null&gt; — optional. Runtime module configuration input.

## Module references

Use `{moduleGivenIdRef: "..."}` inside module input fields that reference another module.

| Scope | Reference |
| --- | --- |
| Same environment | `{moduleGivenIdRef: "module"}` |
| Cross environment, same project | `{moduleGivenIdRef: "environment.module"}` |
| Cross project, same organization | `{moduleGivenIdRef: "project.environment.module"}` |

Use `givenId` values for the project, environment, and module segments.
