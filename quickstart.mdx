Use this guide to get from a Ravion account to your first deployment workflow.

## Prerequisites

Before you begin, make sure you have:

- Access to the [Ravion dashboard](https://app.ravion.com)
- A Git repository for the service you want to deploy
- Access to the cloud account where Ravion will provision infrastructure

## Get started

<Steps>
  <Step title="Create or open your account">
    Sign in to the [Ravion dashboard](https://app.ravion.com). If your team is not set up yet, book a demo from [ravion.com](https://www.ravion.com/book-a-demo).
  </Step>

  <Step title="Connect your cloud">
    Follow the dashboard prompts to connect the cloud account where Ravion should create and manage infrastructure.
  </Step>

  <Step title="Add a project">
    Select the Git repository you want to deploy. Configure the environment, region, and service type for the first workload.
  </Step>

  <Step title="Deploy and verify">
    Start the deployment, then review the deployment status, logs, and generated infrastructure in Ravion.
  </Step>
</Steps>

<Tip>
  Ravion is built for developers and agents to move fast, while platform and DevOps teams keep control.
</Tip>
